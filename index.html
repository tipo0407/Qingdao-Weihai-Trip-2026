02 / 三路人马怎么汇合

目标不是让大家同一架飞机到，而是把到达时间压在同一天下午前后，统一到酒店集合。

A · 你 + 老婆

西雅图 → 上海 → 青岛

8/28：抵达上海，住一晚，倒时差。

8/29：优先从虹桥飞青岛。上海虹桥—青岛直飞非常密集，平均飞行约 1 小时 40 分钟。

建议选 10:00–14:00 左右抵达青岛的航班，避免一早赶机场。
B · 爸妈 + 宝宝

福州 → 青岛

福州—青岛有直飞，当前公开航班数据约每周 20+ 班，平均飞行约 2 小时 15 分钟。

优先：上午起飞、中午前后落地；不追求最低价，优先直飞与宝宝作息。

带宝宝建议托运行李集中在 1–2 件大箱，随身保留奶、尿布、换洗衣物。
C · 丈母娘 + 小舅子

襄阳 → 青岛

公开平台对 2026 夏季直飞信息存在不一致：部分平台显示季节性直飞，另一些显示需中转。

第一版策略：先按 8/29 抵达青岛规划，购票时以携程/航司当天实际可售班次为准。

若没有合适直飞，可优先考虑高铁至武汉/郑州后再飞，避免非常差的航空中转组合。
集合点：不在机场等齐。每一组落地后各自打车去青岛酒店；下午 16:00 左右酒店 lobby 集合。这样宝宝、长辈和国际长途飞行的人都最轻松。

04 / 景点为什么这样取舍

这是“家庭旅行”，不是“景点收集”。第一版把景点按必去 / 可选 / 不建议全家三档处理。

青岛 · 主线保留

八大关 + 第二海水浴场经典树荫多宝宝友好

建筑、林荫和海边一次完成；八大关与第二海水浴场天然相邻。

五四广场 + 奥帆中心轻松夜景

很适合汇合第一天，不需要门票、不需要精确预约。

栈桥 + 老城代表性步行

青岛第一次去值得保留，但控制步数，不把所有“网红路口”一次走完。

威海 · 主线保留

火炬八街 + 国际海水浴场拍照海边

两个点相邻，可组成一个低强度上午；火炬八街本身 1–2 小时已经足够。

刘公岛历史半日~一日

威海最有辨识度的人文景点之一，但乘船受天气影响，所以单独留一天。

威海公园 / 海滨散步免费低强度

给换城日和第一晚使用，不需要为了“打卡”专门折腾。

为什么不把崂山放成全家必去？
崂山本身值得去，但从市区往返、景区交通、坡道和步行量都会放大带 11 个月宝宝与长辈的疲劳。更好的方式是把 9/1 做成“可拆分日”：想去的成年人去，不想折腾的人在市区休息。
为什么不去成山头 / 那香海做整天远郊？
威海阶段只有 4 晚，如果再安排一个远郊整日，会把真正舒服的海滨度假变成赶路。第一版先把经典市区 + 刘公岛走好；如果你们特别想自驾，再在下一版替换 9/5。

05 / 住宿区域建议

暂时不锁具体酒店，先锁“区域”。等你 review 完，我再按预算、房型和是否需要婴儿床筛 3–5 家。

城市首选区域为什么不建议
青岛五四广场 / 奥帆中心附近餐饮、商场、海边、打车都方便；第一晚和晚间散步尤其合适。家庭团住这里比住最老城区更省心。为了“网红海景”住很偏的民宿；7 人 + 宝宝后勤容易麻烦。
威海环翠区市中心 / 威海公园一带去刘公岛码头、餐饮、火车站和海滨都比较均衡；打车去火炬八街也可接受。四晚都住太远的度假区，除非你们决定租车。
房型建议：优先同一家酒店订 3 间房（你们夫妻、爸妈+宝宝、丈母娘+小舅子），最好同层；宝宝房提前问婴儿床、冰箱和是否能提供微波炉/热水。

06 / 11 个月宝宝版本

全程默认“宝宝午睡优先于景点”。这会让所有大人的体验反而更好。

☀️ 防晒 / 防暑

8 月底山东沿海仍可能很晒。海边尽量安排早上和 16:30 后；准备遮阳篷、帽子、防晒和便携小风扇。

🍼 随身包

奶 / 水、辅食、尿布、湿巾、2 套衣服、薄外套、垃圾袋、常用药品单独一包装，不进托运行李。

🚗 城内交通

7 人团建议日常拆成两辆网约车，比全员地铁换乘更轻松。景点之间尽量点到点。

08 / 第一版结论

推荐结构：8/28 上海休息 → 8/29 全家青岛集合 → 青岛 4 晚 → 9/2 高铁去威海 → 威海 4 晚 → 9/6 分头返程。整个行程最重要的不是多去两个景点，而是让 7 个人、尤其宝宝和长辈，都觉得每天还有余力。
